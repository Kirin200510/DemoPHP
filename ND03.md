NỘI DUNG 3: GIẢI THÍCH PHP SESSION($_SESSION,COOKIE)
1. Mục đích
PHP Session: Dùng để lưu trạng thái của người dùng trên server, giúp server nhận biết người dùng giữa nhiều request khác nhau. Ví dụ: sau khi đăng nhập, hệ thống có thể lưu user_id vào session để các trang sau biết người dùng nào đang đăng nhập.
2. Khái niệm
Session: Là cơ chế lưu dữ liệu trên server theo từng phiên làm việc của người dùng.
$_SESSION: Là biến mảng PHP dùng để lưu và đọc dữ liệu của session. Ví dụ: $_SESSION['user_id'] = 123.
Cookie: Là dữ liệu nhỏ được lưu ở trình duyệt. Cookie thường được dùng để lưu Session ID để trình duyệt gửi lại Session ID trong các request tiếp theo.
3. Flow hoạt động của Session + Cookie
Bước 1: Client gửi request đến server.
Bước 2: PHP gọi session_start() để bắt đầu hoặc khôi phục session.
Bước 3: Nếu chưa có session, PHP tạo một Session ID và gửi Session ID về trình duyệt thông qua cookie.
Bước 4: Trình duyệt lưu cookie và gửi cookie này kèm các request tiếp theo.
Bước 5: PHP đọc Session ID, tìm đúng session trên server và khôi phục dữ liệu trong $_SESSION.
Bước 6: Code có thể đọc/ghi dữ liệu, ví dụ kiểm tra $_SESSION['user_id'].
Bước 7: Khi logout hoặc kết thúc phiên, session có thể được hủy bằng session_destroy().
Flow: Browser → Request → PHP session_start() → Session ID/Cookie → Server tìm Session → $_SESSION → Response.
Luồng SSO:
Flow: User A login system A -> server tạo token SSO ->redirect sang system B kèm token -> verify token-> lấy thông tin như user_id,username-> tạo session riêng cho systemB.
